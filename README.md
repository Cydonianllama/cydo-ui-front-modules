# UI/UX Front

Índice de maquetas / clones de interfaz del módulo.

## Demo

Abre `index.html` en el navegador, o sirve la carpeta:

```bash
npx serve .
```

## Proyectos

| Proyecto | Ruta | Descripción | Demo |
|---|---|---|---|
| Google Calendar Composer | `./google-calendar-composer/index.html` | Composer de eventos estilo Google Calendar. Layout aside + contenido, vistas crear / editar y paneles acoplados. | [Abrir](./google-calendar-composer/index.html) |
| Twitch — Channel | `./twitch/index.html` | Clon de página de canal de Twitch: header, sidebar seguidos / en vivo, info del canal, about y chat. | [Abrir](./twitch/index.html) |
| Twitter Profile | `./twitter-profile/index.html` | Clon de perfil de Twitter/X: nav lateral, hero, info de perfil, tabs y asides. | [Abrir](./twitter-profile/index.html) |
| UI Logger | `./ui-logger/` | WIP — solo contiene asset de referencia, sin `index.html` todavía. | — |
